# Contributing

Keep public content in English. Run `make check build` before delivery. Use
conventional commit subjects. Changes to the schema must preserve the documented
`v1` contract or introduce another API version.

Keep facts, runtime compatibility and recommendations separate. A source's
retrieval date is not a verification date. Record the exact host for prices and
limits, retain unknown values, and never infer an alias from a similar name.
New recommendations need a dated source or reproducible evaluation, with the
model, provider and reasoning configuration stated in the evidence.

The daily job reports findings for review. It must retain read-only repository
permissions and never promote external metadata into runtime configuration.
Tests use local fixtures, never credentials or a real model.
